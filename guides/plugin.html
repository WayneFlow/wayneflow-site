What it is

Anthropic, the company behind Claude, open-sourced a set of 11 free plugins for Claude in a public GitHub repo called knowledge-work-plugins (Apache-2.0 license, more than 33,000 stars as of Oct 31, 2026). One of them is Sales. In Anthropic's words, it helps you "research prospects, prep for calls, review your pipeline, draft outreach, and build competitive battlecards."

It works on its own using web search and what you tell it. If you connect tools like your CRM, email or calendar, it can use those too, but you don't need them to start.

The catch: The plugin is free. Claude itself isn't: you need a paid Claude plan to use plugins.

What you need

  • A paid Claude plan
  • Either Claude's Cowork (in the Claude desktop app) or Claude Code
  • 2 minutes, and one sentence about your best customer

Setup option A: Cowork (no code)

  1. Open the Claude desktop app and switch to Cowork.
  2. Go to claude.com/plugins, which is where Anthropic says to install these plugins from.
  3. Find Sales and install it.
  4. Start a new Cowork task and type: "Research [a company you know] as a sales prospect." If you get a company overview, recent news and likely priorities back, it's working.

Setup option B: Claude Code (one command each)

  1. Open your terminal with Claude Code installed.
  2. Add Anthropic's plugin marketplace (copy box below, line 1).
  3. Install the Sales plugin (line 2).
  4. Start Claude Code. The plugin turns on by itself. Its skills run when your request matches, or you can call them by name, like /sales:call-prep.
Claude Code install commands
claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install sales@knowledge-work-plugins

Before anything: tell it who your best customer is

This is the step most people skip, and the reel says it plainly: it won't work unless you tell it who your best customer is. The plugin scores prospects against your ideal customer. If it doesn't know who that is, every company looks like a fit. Paste this once at the start of each session (or save it in your project instructions).

Our best result so far: [a real result with a number, only if true]

If you're missing something you need, ask me once instead of guessing.

Prompt 1: Prospect research (two real details)

Don't ask it to write a hundred emails. Ask it for two real details about one company. In Hunter's study of 31 million cold emails, emails with 2 custom details got a 5.6% reply rate, versus 3.6% with none. Two true, specific details beat ten generic ones.

Prospect research prompt
/sales:account-research

Research [company name] ([website]) as a prospect. Contact: [name, job title] if known.

Give me:
1. A 3-line company overview.
2. Fit against our best customer: good / maybe / no, and why.
3. Exactly TWO real, specific details I could mention in a cold email (a recent hire, launch, expansion, job post, review, quote). For each, give the source link and the date.
4. The one problem they most likely have that we solve.

Only use facts you can link to. If you can't find two real details, say so. Don't guess.

Prompt 2: One-page call prep

Before every call, have it write a one-page brief. Five minutes of reading beats twenty minutes of clicking around their website.

Call prep prompt
/sales:call-prep

I have a call with [name, job title] at [company] on [date]. It's a [first discovery call / follow-up / demo].
How they found us: [cold email reply / form / referral]. What they said: [paste their reply].

Write a one-page brief:
1. Who they are and what the company does (3 lines).
2. Anything new at the company in the last 90 days, with links.
3. Their likely top 2 problems, tied to what we sell.
4. 5 discovery questions, simplest first.
5. 2 objections they might raise and a one-line answer to each.
6. The one next step I should ask for at the end.
Keep it to one page.

Prompt 3: First-draft outreach

First-draft outreach prompt
/sales:draft-outreach

Using the two details you found on [company], draft a first cold email to [name, job title].

Rules:
1. Under 80 words.
2. Line 1 uses detail #1. Work detail #2 in only if it fits naturally.
3. One sentence on the problem, one on the result we get (only real numbers I gave you).
4. End with a low-pressure question, not a meeting request.
5. Plain English, no buzzwords, no exclamation marks.
Give me 2 versions. Don't send anything, just draft.
You do the selling: Treat everything it writes as a first draft. Check every detail is true, read the email out loud, and change anything that doesn't sound like you before it goes out.

Quick answers

Is it really free?

The plugin is free and open source (Apache-2.0). You need a paid Claude plan to run it.

Do I need to connect my CRM?

No. It works with web search and what you tell it. Connecting a CRM, email or calendar just gives it more to work with.

Can it send emails for me?

With email connected it can create drafts or send when you ask. We'd keep it on drafts and check each one yourself before anything goes out.

Will this replace a salesperson?

No. It does the research, prep and first drafts. You still do the selling.
